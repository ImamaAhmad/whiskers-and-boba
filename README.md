# Whiskers & Boba

Welcome to **Whiskers & Boba**, a tiny boba café run by cats.

I made this project for Boba Bash because I really enjoy coding and I also have a cat, so I thought combining the two would be fun. I wanted to make something that felt like more than just a basic webpage with its own little characters and personality.
Check the deployed website on Netlify!!
https://whiskers-and-boba.netlify.app/

## About the Project

Whiskers & Boba includes:

- A boba drink menu
- A meet-the-cats section
- A little story about the café
- A build-your-own-boba section
- Custom CSS illustrations
- A picture of my cat, **Piddu**

The website is made using **HTML and CSS**. I wanted to keep the project strictly HTML and CSS, so I didn't use JavaScript for the drink customization.

## The Boba Builder

The drink customization was one of the biggest challenges for me.

I kept getting errors where the customization wasn't showing up or working properly. I used **AI to help me troubleshoot and fix this part** while working through the problem.

Getting the CSS-only interaction to finally work was one of the most satisfying parts of making the project.

## What I Learned

This project helped me get more comfortable with CSS, especially when creating interactive features without JavaScript.

I also learned that small features can sometimes be surprisingly difficult to get working. I had to experiment quite a bit with the drink builder before I got it working and troubleshooting it taught me a lot.

## Final Note

I wanted Whiskers & Boba to feel like a tiny café with its own characters, story and personality rather than just a collection of HTML and CSS.
